How the rules work

Match rules, strongest first

  1. Same normalised email (lower-case, plus-tag and Gmail dots removed): high confidence.
  2. Same phone number after stripping spaces and country prefix: high.
  3. Same postcode and a name that differs by at most one edit or an initial: medium, flagged for human review.

Governance rules

  • Consent rolls up to the most restrictive value across linked records.
  • A medium-confidence link never merges consent or contact data automatically.
  • Every link records the rule that created it.
