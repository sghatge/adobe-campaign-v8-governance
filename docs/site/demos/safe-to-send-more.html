What does the tool really save?

Needs at least 5 timed trials per method. Uses medians and a bootstrap 90% interval, shows defects found beside time, and labels any yearly figure as a projection. The sample numbers are invented for illustration.

These are JavaScript ports of the Python tools in episodes 03, 08, 15 and 25. The bootstrap in episode 25 uses a different random generator than Python, so its interval can differ slightly from the CLI.
